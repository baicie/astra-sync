# Phase 15: Connector Catalog Lifecycle Automation

## Status

**Complete.** Phase 15 automates the lifecycle of the deployment-authoritative
connector inventory by removing hardcoded build identifiers, adding readable
diagnostics when the catalog drifts, and documenting the author flow for
connector additions and modifications.

## Goals

1. Replace the hardcoded `--compiler-build 0.1.0-SNAPSHOT` literal in
   `Makefile catalog-check` and the CI step with a dynamic value sourced from
   the git commit SHA.
2. Provide a `scripts/diff-catalog.py` tool that prints actionable diagnostics
   when two inventories diverge, replacing the previous bare "files differ"
   message.
3. Provide a `scripts/catalog-info.py` tool that prints a human-readable summary
   of any catalog without rebuilding the CLI jar.
4. Add a `catalog-print` CLI subcommand that decodes a `.pb` file into a
   line-oriented, deterministic, diff-friendly text format.
5. Document the author flow in `docs/catalog-authoring.md`.

## Non-goals

- Changing the catalog wire format (it remains binary protobuf per ADR-040).
- Replacing the catalog generation logic in `ConnectorInventories.create` —
  it is already deterministic and SHA-256 content-addressed.
- Adding new connector types or changing the SPI contract.
- Implementing service-mesh tracing for catalog distribution.
- Auto-bumping version on every PR; the catalog is regenerated by maintainers
  at release time.

## Architectural Boundary

Phase 15 touches:
- The CLI jar (adds `catalog-print` subcommand) — additive, no API change.
- `Makefile` (new targets + dynamic variable).
- `.github/workflows/ci.yml` (catalog-check step uses git SHA + diff-catalog fallback).
- New Python scripts and tests under `scripts/`.

Phase 15 does not touch:
- The connector SPI contract.
- The catalog protobuf schema.
- The control plane catalog-loading path.
- Helm chart, Go control plane, or data plane Java modules outside the CLI.

## Operational Impact

Before Phase 15:
- `make catalog-check` failed spuriously whenever the project version bumped.
- CI failure showed only "files differ".
- No standalone tool to inspect the catalog.

After Phase 15:
- `make catalog-check` is stable across version bumps.
- CI failure prints the actual drift (added/removed descriptors, changed options).
- `make catalog-info` and `make catalog-export` work standalone.
- `docs/catalog-authoring.md` documents the end-to-end flow.
